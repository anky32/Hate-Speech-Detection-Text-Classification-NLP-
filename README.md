# Hate Speech Detection using NLP

## Overview

This project applies Natural Language Processing and Machine Learning techniques to classify hate speech and offensive language.

## Features

- Text preprocessing
- Tokenization
- Lemmatization
- Feature extraction
- Classification model training
- Performance evaluation

## Technologies

- Python
- NLTK
- Scikit-Learn
- TensorFlow
- Pandas

## Dataset

Hate Speech and Offensive Language Dataset
